Agents are redefining DX.
[How] should web standards adapt?

Rick Byers & Lea Verou

The Web Platform's design principles implicitly assume a human developer as the primary API consumer. As a growing share of web code is written by agents, these assumptions stop holding uniformly, and some pull in opposite directions.

Goal: make progress on the session's questions and identify people interested in exploring this further.

The shift has already happened

Web development is moving from human-led to agent-led

Before asking how standards should adapt, establish that the change is real and large. The rest of this section is data, most of it public and reproducible.

Developers stopped asking each other

  • −99% all questions since the 2016 peak
  • 23,799 → 69 [javascript] per month
  • 8,426 → 31 [css] per month

Source: Stack Exchange API, one sample month per quarter (data). Excludes deleted questions.

Counts come straight from the public Stack Exchange API (/2.3/questions?filter=total), sampled every January, April, July and October. Raw numbers are in data/stackoverflow-questions.csv; the script is tools/so_fetch.py.

The slow decline started around 2017 (the easy questions had been answered). ChatGPT (Nov 2022) turned it into a collapse, and coding agents (Claude Code, Copilot agent mode, Cursor agent; early 2025) finished it: July 2026 had about 1,200 new questions, fewer than in the site's first month of public beta in 2008.

Web-platform tags fell even harder than the site overall: [javascript] is down 99.7% from its July 2015 peak, [css] 99.6% from January 2014.

Mintlify 2026 State of Knowledge Report: agent share of traffic on Mintlify-hosted docs grew from 20.8% (Feb 2026) to 66% (Aug 2026); in August, 257M agent requests vs. 131M human page loads; 10.8M /llms.txt fetches and 2M+ MCP tool calls that month. Caveat: human and agent traffic are measured differently (client-side analytics vs. server-side requests), and Mintlify widened its agent detection in June 2026. An earlier user-agent-only snapshot (April 2026) already had agents at 45.3% vs. browsers at 45.8% of ~790M requests, with Claude Code alone at 25%.

Adam Wathan, 7 Jan 2026: “Traffic to our docs is down about 40% from early 2023 despite Tailwind being more popular than ever… our revenue is down close to 80%.”

MDN MCP server, 15 June 2026: “More and more AI tools are being integrated into web development workflows, but they can surface outdated web platform information…”

2026: agents take over

  • 66% of AI users use coding agents or assistants
  • 73% of those use them daily
  • 70% ask an AI agent when looking for answers
  • 24% still use Stack Overflow for work answers

Sources: Stack Overflow Developer Surveys 2023–2026.

2024 survey: 62% currently using AI tools, up from 44% in 2023. 2025 survey: 47.1% daily + 17.7% weekly + 13.7% monthly or less = 78.5% using; 84% using or planning to; 31% already using AI agents.

2026 survey (published 6 Oct 2026): coding agents used by 66% of AI users; 73% of AI coding assistant/agent users use them daily; top agents are Claude Code (66%) and GitHub Copilot (59%). When looking for answers, 83% use search and 70% an AI agent; Stack Overflow is used by 24% for work answers, and people visit “less for simple questions”.

The 2026 agent figures are a share of AI users, not of all respondents, so they don't extend the bar chart directly.

Web development is ground zero

  • 59% of coding conversations with Claude are in JS/TS (31%) or HTML/CSS (28%); UI component work is the #1 task
  • 79% of Claude Code sessions are automation (agent does the task) vs. 49% in the chat app
  • ~4% of all public GitHub commits were authored by Claude Code by February 2026, up from ~0.7% in September 2025
  • 29% of JavaScript developers' code is AI-generated, up from 20% a year earlier

Sources: Anthropic, AI's impact on software development (Apr 2025); SemiAnalysis (Feb 2026); conffab.com commit count; State of JavaScript 2025.

Anthropic Economic Index, 28 Apr 2025, 500K coding conversations: JavaScript/TypeScript 31% and HTML/CSS 28% of queries; “UI/UX Component Development” 12% and “Web & Mobile App Development” 8% of tasks. Claude Code 79% automation vs. 49% on Claude.ai. This data predates the 2025–26 agent boom.

SemiAnalysis, 5 Feb 2026: ~4% of public GitHub commits authored by Claude Code. An independent count found ~0.7% in late Sept 2025 and 4.5% by mid-March 2026. These only count commits that carry an attribution trailer, so they are a floor and cover one agent.

State of JavaScript 2025: share of code that is AI-generated rose from 20% to 29% year over year (median answer 25%).

The primary reader of the web platform is changing

  • Developers have stopped asking each other: new Stack Overflow questions are down 99%
  • Agents read docs twice as often as humans do (Mintlify, Aug 2026)
  • Coding agents are mainstream, and web code is where they work most

Standards, docs and APIs were designed for a human reading MDN. That is no longer the typical consumer.

Bridge to the discussion: if the typical “developer” reading a spec, an MDN page or an error message is now an agent, which of our design principles still hold, and which pull in the opposite direction?
