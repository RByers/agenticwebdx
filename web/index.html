Agents are redefining DX.
[How] should web standards adapt?

Lea Verou & Rick Byers

The Web Platform's design principles implicitly assume a human developer as the primary API consumer. As a growing share of web code is written by agents, these assumptions stop holding uniformly, and some pull in opposite directions.

Goal: make progress on the session's questions and identify people interested in exploring this further.

The shift has already happened

Web development is moving from human-led to agent-led

Before asking how standards should adapt, establish that the change is real and large. Three slides of public data; every number links to its source.

Developers stopped asking each other

  • −99% all questions since the 2016 peak

  • 8,426 → 31 [css] per month

Source: Stack Exchange API, one sample month per quarter (data, script). Excludes deleted questions.

Counts come straight from the public Stack Exchange API (/2.3/questions?filter=total), sampled every January, April, July and October. Raw numbers are in data/stackoverflow-questions.csv; the script is tools/so_fetch.py. The source link on the slide is the live query for July 2026 (1,175); change the tag or dates to reproduce any other point. Re-verified against the API on 27 Oct 2026.

The slow decline started around 2017 (the easy questions had been answered). ChatGPT (Nov 2022) turned it into a collapse, and coding agents (Claude Code, Copilot agent mode, Cursor agent; early 2025) finished it: July 2026 had about 1,200 new questions, fewer than in the site's first month of public beta in 2008.

Web-platform tags fell even harder than the site overall: [javascript] is down 99.7% from its July 2015 peak, [css] 99.6% from January 2014.

MDN, June 2026

Mozilla ships an official MDN MCP server so coding agents get current docs and browser-compat data directly.

Sources: Mintlify, 2026 State of Knowledge Report; tailwindlabs/tailwindcss.com#2388 (comment); MDN blog.

Mintlify 2026 State of Knowledge Report: agent share of traffic on Mintlify-hosted docs grew from 20.8% (Feb 2026) to 66% (Aug 2026); in August, 257M agent requests vs. 131M human page loads; ~10.8M /llms.txt fetches and 2M+ MCP tool calls that month. Caveat (stated in the report): human and agent traffic are measured differently (client-side analytics vs. server-side requests), so the comparison is an estimate. An earlier user-agent-only snapshot (March 2026, published 3 Apr) already had agents at 45.3% vs. browsers at 45.8% of ~790M requests, with Claude Code alone at 25%.

Adam Wathan, 7 Jan 2026, on a PR proposing LLM-friendly docs: “Traffic to our docs is down about 40% from early 2023 despite Tailwind being more popular than ever… our revenue is down close to 80%.” and “75% of the people on our engineering team lost their jobs here yesterday.”

Introducing the MDN MCP server, 15 June 2026: “More and more AI tools are being integrated into web development workflows, but they can surface outdated web platform information based on their training data and knowledge cutoff.”

Standards, docs and APIs were designed for a human reading MDN. That is no longer the typical consumer.

Sources: Stack Overflow Developer Survey 2024, 2025, 2026; Anthropic, AI's impact on software development (Apr 2025).

2024 survey: 61.8% currently using AI tools in their development process, up from 44% in 2023 (“62% vs. 44%”). 2025 survey: 47.1% daily + 17.7% weekly + 13.7% monthly or less = 78.5% using; 84% using or planning to; 31% already using AI agents.

2026 survey (published 6 Oct 2026; full results at survey.stackoverflow.co/2026): “73% of respondents who indicate using AI coding assistants/agents use them daily”; 66% of AI users use coding agents; the agents of choice are Claude Code (66%) and GitHub Copilot (59%). “83% still ask a search engine for answers, but 70% hit up their AI” (16,664 respondents); Stack Overflow is a source of work-related answers for 24%. The 2026 report doesn't publish an overall “currently using” share comparable to 2023–25, so the bar chart stops at 2025.

Anthropic Economic Index, 28 Apr 2025, 500K coding conversations sampled 6–13 April 2025: JavaScript/TypeScript 31% and HTML/CSS 28% of queries; “UI/UX Component Development” 12% and “Web & Mobile App Development” 8% of tasks. Also: 79% of Claude Code sessions are automation (the agent does the task) vs. 49% on Claude.ai. This predates the 2025–26 agent boom.

Backup, not on the slide: State of JavaScript 2025, “What proportion of the code you produce is AI-generated?”: 29%, up from 20% the previous year (median 25%).

Bridge to the discussion: if the typical “developer” reading a spec, an MDN page or an error message is now an agent, which of our design principles still hold, and which pull in the opposite direction?
