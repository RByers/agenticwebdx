# TPAC 2026 slide template

The unmodified files of the [W3C TPAC 2026 slide template](https://www.w3.org/2026/Talks/TPAC/Templates/), which the deck ([`../index.html`](../index.html)) loads. Don't edit them: put custom styles in the deck itself, and put the deck's own images in [`../images/`](../images/). This README is the only file here that isn't part of the template.

- `Overview.html` – the template's example deck and user manual; see it for the available slide classes and layouts (cover, part, final, two-column, etc.)
- `slides.css` – the template's styles
- `b6plus.js` – the b6+ slide framework; `shower.js` – the alternative Shower framework; `iframe-fixup.js` – helper for slides in iframes
- `slides.json` – metadata for the b6+ slide editor
- `*.svg`, `*.png`, `*.jpg` – backgrounds (cover, part, two-panes, light/dark), icons and example images
- `NotoSans-*.woff2` – the Noto Sans fonts the template uses
